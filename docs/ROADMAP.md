# Roadmap

Приложението се изгражда на фази, за да имаме работещ, тестваем продукт на всяка стъпка, вместо да строим всичко наведнъж.

## Фаза 0 — Setup
- Инициализация на backend проект (FastAPI + SQLAlchemy + Alembic), SQLite база
- Инициализация на frontend проект (React + TypeScript + Vite)
- Базова комуникация backend ↔ frontend (health check endpoint)

## Фаза 1 — Основни данни (settings, контрагенти, продукти)
- CRUD за `company_settings` (само една активна конфигурация)
- CRUD за `counterparties`
- CRUD за `products`
- Базов UI за всяко от горните (списък, добавяне, редакция, изтриване)

## Фаза 2 — Издаване на фактури
- Логика за генериране на последователен номер на фактура
- Форма за създаване на фактура: избор на контрагент, добавяне на редове (продукти), автоматично изчисление на суми и ДДС
- Логика за "снимане" на данни (denormalization) към момента на издаване
- Списък и преглед на издадени фактури

## Фаза 3 — Справки и полиране
- Филтриране/търсене на фактури (по контрагент, период, статус)
- Печат / PDF export на фактура
- Основни справки (обороти по период, по контрагент)

## Фаза 4 — Production readiness
- Миграция от SQLite към PostgreSQL (locally, тест на процеса)
- Deployment setup (env variables, Docker, избор на hosting)
- Basic authentication (дори за един потребител, ако не е направено по-рано)

## Извън обхват за момента (бъдещи разширения)
- Multi-user / роли с различни права
- Multi-currency
- Кредитни известия / сторно фактури
- Интеграция с НАП / електронно фактуриране (е-Фактура)
